# МИР СОШЁЛ С УМА! — мод для Minecraft 1.21.11 (Fabric)

Безумные мобы, 25 случайных событий, 10 предметов с реальной механикой, босс **Свиной Император**,
скрытая система безумия, 7 достижений. Только Fabric + Fabric API, без сторонних библиотек.

> ВАЖНО. Проект написан без доступа к компилятору Minecraft: JAR здесь **не собирался и не запускался**.
> Исходники прошли только проверку синтаксиса (49 файлов разобраны javac без ошибок), но не компиляцию против
> Minecraft 1.21.11. Из-за этого возможны мелкие ошибки в названиях методов Yarn — они правятся за минуты,
> пришлите текст ошибки `gradle build`. Раздел «Где вероятны ошибки» ниже.

## Сборка

Нужны: **JDK 21**, **Gradle 9.2+** (или IntelliJ IDEA, которая сама поставит Gradle) и интернет.

```
gradle wrapper --gradle-version 9.2.1     # один раз, создаст gradlew
./gradlew build                           # Windows: gradlew.bat build
```

Готовый мод: `build/libs/madworld-1.0.0.jar` (файл `-sources.jar` не нужен).
Для проверки в игре: `./gradlew runClient`.

## Установка

1. Установите Fabric Loader 0.18.x для Minecraft 1.21.11 и **Fabric API 0.141.1+1.21.11** (или новее для 1.21.11).
2. Положите `madworld-1.0.0.jar` в папку `mods`. Мод нужен и на сервере, и у игроков.

## Что внутри

**Мобы:** Крипер-курьер, Свинья-босс = Свиной Император, Зомби-танцор, Деревенский сумасшедший,
Курица-ниндзя, Элитный скелет. У каждого своя модель, текстура, характеристики и поведение.

**События (25):** гравитация в отпуске, куриная эпидемия, небо падает, перевёрнутое управление (W↔S, A↔D),
богатые свиньи, обиженные блоки, космическая доставка (сундук), вторжение утёнков, танцы без тормозов,
крипер-курьер, радужное стадо, куры выросли, все крошечные, картошка для всех, звуковая путаница,
пол — батут, затмение, золотая лихорадка, левитация, королевский указ (вызов босса), сумасшедший, набег кур-ниндзя,
элитные скелеты, телепортационный чих, банановый шторм.

**Предметы:** Банановая граната, Пульт хаоса (ПКМ — событие, Shift+ПКМ — обряд босса), Молоток судьбы (30 % — превращает моба),
Суп скорости, Кубик удачи, Рог апокалипсиса, Палка телепортации, Золотой унитаз (блок, редко в сундуках, ПКМ — слив),
Магнит для свиней, Запрещённая картошка. Дополнительно: Банановая кожура, Золотая картофелина (метательная), Корона императора (трофей).

**Свиной Император:** 500 HP, 3 стадии (66 % и 33 %), полоска здоровья, прыжок с ударной волной,
золотые картофелины, до 8 свиней-помощников, реплики при уроне, награда и трофей.
Появляется ТОЛЬКО при всех условиях: безумие ≥ порога (по умолчанию 75 %), Верхний мир, под открытым небом,
не «мирная» сложность, босса нет в мире, прошло ≥ 20 минут с прошлого вызова. Вызов: событие «Королевский указ»
или Shift+ПКМ Пультом хаоса.

**Безумие:** растёт от использования предметов, событий, убийства новых мобов, находок. Чем выше — тем чаще события
и тем больше необычных мобов (с лимитом). Хранится в `<мир>/madworld_state.txt`. Остывает на 1 каждые ~2,5 минуты.

**Достижения:** Я просто хотел добыть дерево (событие в течение минуты после рубки дерева), Курица знает слишком много,
Это точно Minecraft? (50 % безумия), Король свиней, Картошка изменила мою жизнь, Пережил полный хаос (10 событий),
секретное «Слив королей».

**Секреты:** танец заразителен (соседние мобы мода пускаются в пляс), курицы-ниндзя воруют даже посылки курьера,
золотой унитаз иногда возвращает подарки, скелеты случайно стреляют по соседним мобам.

## Настройка — `config/madworld.json`

| Параметр | По умолчанию | Смысл |
|---|---|---|
| eventsEnabled | true | включить события |
| minIntervalSeconds / maxIntervalSeconds | 120 / 360 | интервал между событиями (при высоком безумии до −40 %) |
| maxExtraMobs | 40 | лимит созданных модом существ в измерении |
| madnessEnabled | true | включить систему безумия |
| startMadness / maxMadness | 0 / 100 | начальный и максимальный уровень |
| madnessGainMultiplier | 1.0 | множитель прироста |
| bossMadnessPercent | 75 | порог безумия для босса, % |
| naturalMadMobs / naturalSpawnChanceAtMax | true / 0.35 | самопроизвольное появление мобов |
| disabledEvents | [] | id отключённых событий |

## Защита от перегрузки и от поломки выживания

Максимум 2 события одновременно (3 при ручном запуске); все существа событий имеют лимит и срок жизни
(они исчезают с дымком, даже после перезапуска сервера); временные изменения (рост кур, «jeb_» овцам) откатываются
после перезапуска; все задачи и обработчики обёрнуты в try/catch; число отложенных задач ограничено 256;
враждебные мобы исчезают в мирной сложности; события не убивают игрока (прыжки/левитация идут с медленным падением);
эффекты не трогают блоки мира, кроме одного сундука «космической доставки».

## Команды (консоль или одиночная игра)

`/madworld status`, `/madworld event <id>`, `/madworld madness <число>`, `/madworld boss`, `/madworld spawn <моб>`.

## Где вероятны ошибки компиляции (проверить в первую очередь)

Код написан под Yarn 1.21.11+build.4 по памяти и документации; места, где названия могли поменяться:

1. `client/MadMobModel.java` — поля состояния рендера `limbFrequency`, `limbAmplitudeMultiplier`, `relativeHeadYaw`, `pitch`, `age`.
2. `client/MadModels.java` (генерируется) — `ModelTransform.of(...)`.
3. `item/BananaGrenadeItem.java`, `GoldenPotatoItem.java` — `ProjectileEntity.spawnWithVelocity` и конструкторы `(World, LivingEntity, ItemStack)` у снарядов.
4. `entity/EliteSkeletonEntity.java` — конструктор `ArrowEntity(World, LivingEntity, ItemStack, ItemStack)`.
5. `item/ModItems.java` — `Item.Settings.sword(...)`, `food(...)`, `useRemainder(...)`.
6. `MadHooks.java` — подпись `LootTableEvents.MODIFY` и `PlayerBlockBreakEvents.AFTER`.
7. `entity/MadMobEntity.java`, `PigEmperorEntity.java` — `damage(ServerWorld, DamageSource, float)`, `onDeath`, `onStartedTrackingBy`.

Сгенерированные файлы (`MadModels.java`, текстуры) создаются `tools/gen_assets.py` (нужен Python + Pillow);
менять модели удобнее там — геометрия и UV остаются согласованными.
